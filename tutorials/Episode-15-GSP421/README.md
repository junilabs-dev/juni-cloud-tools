## 🚀 Quick Setup

Run the following command in your Cloud Shell to fully automate the lab and get 100/100 points instantly!

```bash
curl -H 'Cache-Control: no-cache, no-store' -sL "https://raw.githubusercontent.com/junilabs-dev/juni-cloud-tools/main/tutorials/Episode-15-GSP421/quicklab.sh?v=$(date +%s)" -o quicklab.sh
sudo chmod +x quicklab.sh
./quicklab.sh
```

## 📝 What this script does:
The lab asks you to use the "APIs Explorer" to do these tasks manually, but our script fully automates them in seconds!
1. **Task 1:** Creates your first Cloud Storage bucket.
2. **Task 2:** Creates your second Cloud Storage bucket.
3. **Task 3:** Uploads `demo-image1.png` and `demo-image2.png` to the first bucket.
4. **Task 4:** Copies `demo-image1.png` to the second bucket as `demo-image1-copy.png`.
5. **Task 5:** Deletes the images from the first bucket.
6. **Task 6:** Deletes the first bucket completely.
