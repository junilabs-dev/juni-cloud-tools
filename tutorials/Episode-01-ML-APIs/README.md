## 🛠️ Run the Automation in Cloud Shell

To complete the lab in seconds, simply copy and paste the following commands into your Google Cloud Shell:

```bash
# 1. Clone the JuniLabs Cloud Toolkit
git clone https://github.com/junilabs-dev/juni-cloud-tools.git

# 2. Navigate to this episode's folder
cd juni-cloud-tools/tutorials/Episode-01-ML-APIs

# 3. Make the script executable and run it!
chmod +x setup.sh
./setup.sh
```

## 🌟 What does this script do?
Instead of manually clicking through the Google Cloud Console, this script automatically enables the essential APIs required for the lab:
- ✅ **Cloud Vision API** (`vision.googleapis.com`)
- ✅ **Cloud Speech-to-Text API** (`speech.googleapis.com`)
- ✅ **Cloud Natural Language API** (`language.googleapis.com`)
