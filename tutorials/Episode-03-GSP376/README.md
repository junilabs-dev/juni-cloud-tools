This directory contains the cheat sheet for the **Get Started with Google Workspace Tools: Challenge Lab (GSP376)**.

## ⚠️ NO AUTOMATION SCRIPT!
**Why no `setup.sh`?** 
This is a **Google Workspace** lab, not a Google Cloud (GCP) lab! You do not get access to Cloud Shell or a Linux terminal here. All tasks must be done manually in the browser (Gmail, Calendar, Drive, Sheets, AppSheet). 

Here is the exact Step-by-Step Cheat Sheet to complete this lab in 2 minutes! 🚀

---

## 📝 Step-by-Step Cheat Sheet

### Task 1: Create your signature
1. Open [Gmail](https://mail.google.com).
2. Click the **Gear icon (Settings)** in the top right -> **See all settings**.
3. Scroll down to the **Signature** section.
4. Click **+ Create new**, name it `My Signature`.
5. Type your name and contact info in the text box.
6. Under **Signature defaults**, select `My Signature` for "For new emails use".
7. Scroll to the very bottom and click **Save Changes**.

### Task 2: Add out-of-office dates to your calendar
1. Open [Google Calendar](https://calendar.google.com).
2. Click on today's date to create an event.
3. Select the **Out of office** tab at the top of the event popup.
4. Title it exactly: `OOO Orientation`.
5. Set the dates for the next **3 days** (or just leave the default multi-day span).
6. Click **Save** and then **Save & Decline** (if prompted).

### Task 3: Create a folder in your Google Drive
1. Open [Google Drive](https://drive.google.com).
2. Click the **+ New** button on the top left.
3. Select **New folder**.
4. Name it anything (e.g., `Project Info`) and click **Create**.

### Task 4: Schedule weekly status meetings
1. Go back to [Google Calendar](https://calendar.google.com).
2. Click **+ Create** -> **Event**.
3. Title it (e.g., `Weekly Status`).
4. Click on the date/time, click the **Does not repeat** dropdown, and select **Custom...** -> Repeat every **1 week** -> **Done**.
5. In the **Add guests** box, paste the email addresses for **Colleague 1** and **Colleague 2** (find these in your Qwiklabs instruction panel).
6. Click **Save** -> **Send** invitations.

### Task 5: Create and share a task spreadsheet
1. Open [Google Sheets](https://sheets.google.com).
2. Click **Blank** to create a new spreadsheet.
3. Click on "Untitled spreadsheet" at the top left and rename it EXACTLY to: `Project Task Sheet`.
4. In the first row (A1 to E1), type these exact headers:
   - `Tasks`
   - `Owner`
   - `Priority`
   - `Status`
   - `Comments`
5. Click the large green **Share** button in the top right.
6. Paste the emails for **Colleague 1** and **Colleague 2** and click **Send**.

### Task 6: Create an AppSheet application
1. Go to [AppSheet](https://www.appsheet.com/) (Make sure you are in the Incognito window with the student account).
2. Click **Start for free** -> Select **Google**.
3. Authorize with your Qwiklabs student account by clicking **Allow**.
4. Click **Make a new app** (or **Create** -> **App**).
5. Select **Start with your own data**.
6. Name the app anything, choose any category.
7. Click **Choose your data** -> Select Google Drive -> Select the `Project Task Sheet` you just created.
8. Wait for the app to generate. Once the editor opens, you are done!

🎉 **Go back to Qwiklabs and click "Check my progress" on all tasks. 100/100!**
